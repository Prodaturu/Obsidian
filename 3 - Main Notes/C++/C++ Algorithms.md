# C++ Algorithms

> Algorithmic techniques and problem-solving patterns in C++.

Algorithms describe **step-by-step procedures** for transforming data,
solving problems, and performing computation efficiently.

In C++, algorithms are shaped by:
- the available data structures
- iterator-based abstractions
- value vs reference semantics
- performance and complexity constraints

They range from **generic library algorithms** to **custom problem-specific
solutions**.

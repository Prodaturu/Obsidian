### Why we need casting with `std::toupper`

####
```cpp
std::cout << std::toupper(str[i])
```

- This would throw an error, because `std::toupper` doesn't return `char`
	- It takes an `int`
	- returns an `int`
- Signature of `std::toupper` is:
```cpp
int  std::toupper(int c);
```

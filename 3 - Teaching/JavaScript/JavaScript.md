# JavaScript

> Main hub for all JavaScript notes.

- JavaScript is a high-level, general-purpose programming language.
	- Originally created to make web pages interactive.
	- Today it powers web applications, backend servers, desktop applications, mobile applications, serverless platforms and more.

- JavaScript is dynamically typed.
	- Types are determined during execution rather than compilation.
	- Variables can reference values of different types throughout their lifetime.

- JavaScript is prototype-based.
	- Objects inherit behaviour through prototype chains rather than classical inheritance.

- JavaScript supports multiple programming paradigms.
	- Procedural Programming
	- Object-Oriented Programming
	- Functional Programming
	- Event-Driven Programming

- JavaScript follows the ECMAScript specification.
	- ECMAScript defines the language standard.
	- JavaScript engines implement this specification.

- JavaScript is most commonly associated with web browsers.
	- However, the language itself is independent of the browser.
	- Browser APIs, Node.js APIs and other runtimes extend JavaScript with additional capabilities.
